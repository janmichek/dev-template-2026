- Rule code is unmodified. Local policy lives in this repository instead:

    `oxc/no-accumulating-spread` companion.
  - `anti-slop/no-runtime-typeof` uses `allowInTypeGuards` for

  - `bun run lint` and `.oxfmtrc.json` ignore `tools/oxlint/anti-slop`, so the
    vendored code is neither linted nor reformatted. `config/.fallowrc.json`
    ignores it too.
  - `src/shared/api/schema.d.ts` is generated by `bun run api:generate`, so lint
    skips it.

Keep `vendor/eslint-stylistic/LICENSE` and `UPSTREAM.md` next to the code they
cover. To update, diff the upstream `src/` against this directory and port the
changes; do not replace local edits wholesale.
